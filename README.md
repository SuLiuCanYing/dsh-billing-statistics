# llm-usage-insights

按平台与模型统计 DeepSeek Harness 里的模型调用：次数、token、花费，数据全部留在本机，侧栏一键打开。

- 按 **平台 / 模型** 汇总调用次数、失败与中止次数、输入 / 输出 / 缓存命中 token、花费。
- 花费按 **峰谷时段** 与 **阶梯价** 计算，峰谷判断固定北京时间（UTC+8）。
- 价格优先取 **平台官网**（可手动填价格页链接，也能自动搜索），抓不到时退回内置参考价；每种价格来源在页面上都有标记。
- 历史按 **小时桶** 保存（`usage.json` v2），每天的明细可以下钻到小时。
- 默认保留 30 天，超出部分在下次启动时清理；总量随裁剪重算，不会漂移。
- 界面中英双语，跟随宿主语言切换。

## 安装

插件市场暂未上架，按本地开发插件安装：

```powershell
# 1. 把本目录放到工作区
# 2. 在 profile 的 package.json 里登记为依赖（link: 形式即可）
# 3. 重启应用，在侧栏看到「用量统计」入口
```

依赖只有 `@deepseek-ai/schemastery`（peer，可选），无需构建。

## 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `retainDays` | 30 | 按天明细保留天数（1–3660），更早的小时桶在下次启动时清理。 |
| `showCost` | true | 页面是否显示花费列与合计。 |
| `priceSync` | true | 每天同步一次官网价格；当天没开程序则下次启动补抓。 |
| `autoDiscover` | true | 没填链接的平台自动搜索价格页，只采纳像「价格 / 计费」的页面。 |
| `priceFeeds` | {} | `provider → 价格页链接` 预设，页面里的输入框优先级更高。 |
| `usdToCny` | 7.1 | 通用页面抓到美元价时的折算汇率。 |
| `peakHolidays` | [] | 视为空闲时段的日期（`YYYY-MM-DD`，北京时间），如法定节假日。 |
| `pricing` | {} | 自定义价格表，键可为 `provider` / `provider/model` / `*`；同名键整体覆盖官网价，全 0 视为未定价。 |

价格匹配顺序：**自定义 `pricing` → 官网价格表 → 内置参考价**。

## 数据与隐私

- 数据目录：`$DSH_HOME/llm-usage-insights/`（默认 `~/.dsh/llm-usage-insights`）。
- `usage.json` 只含计数、token 与价格来源，**不保存任何 prompt / 回复内容**。
- 写盘用「临时文件 + 重命名」，断电不会留下半个 JSON；写入失败会保留脏标记并在下次重试。
- 页面路由仅允许**同源 / 环回地址**访问，并且优先看宿主的 `requestRejection` 判定。

## 已知限制

- 自动找价格页依赖宿主的搜索服务（桌面端要配 DeepSeek 官方 API Key）；没有搜索服务时只能用内置价或手填链接。
- 官网解析目前只针对**硅基流动**与 **DeepSeek 官方**的页面结构，别家平台需手填或走通用解析。
- 峰谷时段固定按北京时间（UTC+8），暂不支持其它时区。
- `usage.json` 未做多实例互斥，同一数据目录被两个进程同时写会互相覆盖。
- 暂无 CSV / JSON 导出。
